About this demo

This is a portfolio demonstration of an illustrated, step-by-step interface. All phases are fictional. Dose, schedule and instruction fields are placeholders.

Try the interaction

Choose an example phase, select a few supplies, and move through its medication cards. Try Back, the section tabs and the illustrated transitions. Optional checks never block navigation.

Designed for changing plans

Earlier examples remain visible alongside a featured example. The interface separates a version of a plan from a record of medication taken.

Built with Codex

Codex supported iterative interface development, original vector illustrations, keyboard navigation, responsive checks and privacy testing. Human review guided the design decisions.

A future community template

Reusable interface code and fictional content are separated. A community template is planned; this demo is not medically reviewed or ready for unsupervised clinical reuse.

Local and self-contained

No accounts, analytics, embedded videos or remote storage. This demo does not read or save browser storage. Clinical sources and contact details are deliberately absent.
